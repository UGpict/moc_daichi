# SougiAgent

親の葬儀を事前に準備する本人・子ども世代向けの、操作可能な Web モックです。
担当のしるべさん（AIサポート）が、見積もりの不明点確認から家族への引継ぎ、火葬許可証の受領・引渡しまでを同じ流れで支援します。

## できること

- 見積書の照合・質問案作成・再計算を自動で進め、外部問い合わせだけ承認する
- 曖昧な返信を完了扱いにせず、再質問や完了報告を待つ
- 確認できた条件から参考額を計算し、家族向けの準備書に残す
- 死亡後の手続きデモ（受領確認、本籍の確認先、日程変更、提出、照会、許可証）

最安値への誘導はしません。本人の希望に沿って、想定外の支出と家族の迷いを減らすことが目的です。

## 起動方法

必要環境: Node.js 22 以降、npm

```bash
npm install
npm run dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開きます。

## デモ操作順

### 生前の準備

1. `/` で「生前の準備を体験する」
2. 案件ホームで、しるべさんがまとめた質問を承認する
3. 初回返信のあと、搬送費が未確定である理由を確認し、再質問を承認する
4. 参考額と家族向け準備書を見る

### 家族への引継ぎ・手続き

1. `/` で「家族への引継ぎ・手続きを体験する」、または家族向け画面から入る
2. 死亡診断書の受領と、本籍の確認先（推測では埋めない）を見る
3. 「火葬日程の変更案」デモ操作、または自動再生で翌日案を受け取る
4. 参考額が 710,500円になり、申請書案の日付不一致が表示される
5. 「この内容で調整を依頼する（デモ）」を承認する（この時点では予約確定しない）
6. 確定報告・提出・自治体照会・「対応します」（未完了）・完了報告・交付／受領／引渡しを順に確認する

各画面の「デモ操作」から、サンプル返信や交付連絡を個別に発生できます。
「デモを自動再生」は外部イベントを順に進め、承認が必要なところで止まります。

「最初からやり直す」で保存状態と進行中の演出を初期化します。
直接 URL を開いても空白やエラーにはなりません。

## 検証

```bash
npm test
npx tsc --noEmit
npm run lint
npm run build
```

金額計算、問い合わせ遷移、日程変更、照会の未完了判定のテストを `src/lib/*.test.ts` に置いています。

## Vercel へのデプロイ

このリポジトリは Next.js App Router の標準構成です。実際の公開操作はこのモック作業では行いません。

1. [Vercel](https://vercel.com) に GitHub リポジトリを連携する
2. Framework Preset は Next.js のままで問題ありません
3. ビルドコマンド `npm run build`、出力は Next.js 既定
4. 環境変数は不要です（バックエンド・認証・LLM API はありません）

CLI を使う場合:

```bash
npx vercel
```

## 制約

- 固定シナリオの体験版です。外部送信はありません
- 実際の送信・契約・予約・届出・許可判断は行われません
- 自治体によって手順は異なります。全国共通の案内ではありません
- 今回の手続きデモは、斎場予約を先に進める想定です
- 届出人・窓口への持参者・火葬許可申請者は別の役割として表示します
- 本籍などの不足情報は推測で埋めません
- 「対応します」だけでは照会完了にしません
- 許可証の交付・受領・引渡しは独立した確認です
- 「火葬実施済み」「葬儀完了」とは表示しません
