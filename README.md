# しるべ／SougiAgent

本人の話を聞いて葬儀の希望とその理由を整理し、共有を許可された情報を家族に引き継ぐ操作可能な Web モックです。しるべは本人を再現する存在ではなく、聞いたことを覚えている担当者として振る舞います。

本人への価値は、「話すことで、自分の希望が家族の使える準備になること」。
家族への価値は、「本人の希望を踏まえて、必要な判断と手続きを進められること」。

## できること

- 会話（文字と短い選択肢）で、一度に一つだけ質問する
- 「まだ分からない」「今日はここまで」でも止められる
- 本人が話したこと、しるべの解釈、確認した希望、外部の事実を分けて残す
- 「質素でいい」を、確認なしに直葬希望へ確定しない
- 見積もりの不足を葬儀社へ聞いてよいか確認し、曖昧な返事は未解決のまま再質問する
- 家族へ残す範囲を本人が選ぶ。私的な相談は自動では共有しない
- 時間経過を明示して、招待済み家族の画面へ切り替える
- 生前の「日程は家族に任せる」を、死後の提案理由として使う
- 家族の訂正は家族の判断として残し、本人の発言は上書きしない
- 火葬許可証の受領・引渡しまで、架空の一案件として追う

## 起動方法

必要環境: Node.js 22 以降、npm

```bash
npm install
npm run dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開きます。

## デモ操作順

### 本人（モックではお母さん）

1. `/` で「準備をはじめる」
2. 「子どもには迷惑をかけたくない」の意味を、一つずつ話す
3. 「家族だけ」「日程は家族に任せる」などを確認する
4. 「お話をまとめました」で、合っている／直したい／まだ決めないを選ぶ
5. 見積もりの不足を聞いてよいか答え、サンプルの返事を見る
6. 家族に残す内容と相手を選ぶ
7. 「時間が経ちました」で家族の画面へ切り替える

### 家族

1. 本人の希望・確認済み・未決定を分けて見る
2. 到着の見込みを伝え、しるべの日程候補を見る
3. 到着や呼びたい人を直すと、提案と確認内容が変わる
4. 手続きの不足を確認し、許可証の受領・引渡しまで進める

親向けの画面ではデモ操作パネルは出しません。返事は自動で届きます。
承認や家族の判断は、自動では行いません。

「最初からやり直す」で保存状態を初期化します。

## 検証

```bash
npm test
npx tsc --noEmit
npm run lint
npm run build
```

会話と記憶、金額計算、問い合わせ遷移、日程変更のテストを `src/lib/*.test.ts` に置いています。

## 制約

- 固定シナリオの体験版です。外部送信はありません
- 実際の送信・契約・予約・届出・許可判断は行われません
- 自治体によって手順は異なります。全国共通の案内ではありません
- 本番の死亡確認・アクセス権切替は別途設計が必要です。モックでは明示的な場面切替で再現します
- 本籍などの不足情報は推測で埋めません
- 許可証の交付・受領・引渡しは独立した確認です
- 「火葬実施済み」「葬儀完了」とは表示しません
