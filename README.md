# しるべ

親の葬儀を事前に準備する本人・子ども世代向けの、操作可能な Web モックです。
見積書の不明点を確認し、家族が使える準備書にまとめる体験を、架空データだけで再現します。

## できること

- 見積書のプレビューを見て、含まれない費用・単価の欠落に気づく
- 葬儀社への質問を承認し、曖昧な返信に再質問する
- 確認できた条件から参考額を計算し、家族向けの準備書として残す

最安値への誘導はしません。本人の希望に沿って、想定外の支出と家族の迷いを減らすことが目的です。

## 起動方法

必要環境: Node.js 22 以降、npm

```bash
npm install
npm run dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開きます。

## デモ操作順

1. `/` で「サンプルで体験する」を押す
2. 準備ホームで前提を確認し、「見積もりを確認する」
3. 見積書プレビューと確認項目を読み、「質問内容を確認する」
4. 質問文を確認し、「この内容で問い合わせる（デモ）」
5. 初回返信のあと、搬送費が未確定である理由を確認し、「再質問する（デモ）」
6. 4件の回答が揃ったら「費用と準備書を見る」
7. 安置日数・搬送距離・夜間搬送を変え、参考合計が更新されることを確認する
8. 「家族から見た画面を開く」で、家族向けの読み物を確認する

「最初からやり直す」で保存状態と進行中の演出を初期化できます。
`/demo/family` は直接開いても空白になりません。同じブラウザでは変更した条件を引き継ぎます。

## 検証

```bash
npm test
npx tsc --noEmit
npm run lint
npm run build
```

金額計算と問い合わせ状態遷移のテストを `src/lib/*.test.ts` に置いています。

## Vercel へのデプロイ

このリポジトリは Next.js App Router の標準構成です。実際の公開操作はこのモック作業では行いません。

1. [Vercel](https://vercel.com) に GitHub リポジトリを連携する
2. Framework Preset は Next.js のままで問題ありません
3. ビルドコマンド `npm run build`、出力は Next.js 既定
4. 環境変数は不要です（バックエンド・認証・LLM API はありません）

CLI を使う場合:

```bash
npx vercel
```

## 制約

- 体験版です。表示データはすべて架空です
- 問い合わせの自動判定は固定シナリオです。実際の送信・契約・予約は行われません
- 見積書アップロード、OCR、LLM、メール、決済、3社比較、ユーザー登録は対象外です
- 実在する葬儀社の情報は使っていません
- 確認日は架空の固定日（2026年4月12日）です
- 参考合計は条件に基づく計算結果であり、将来の総額や空き状況を保証しません
