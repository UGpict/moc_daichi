# しるべ／SougiAgent

死亡後の家族が、本人の残した記録を手掛かりに手続きを進める操作可能な Web モックです。最初の一本は、**書類に一つ不備がある案件を、関係者への確認で完了させる**体験です。

生前の長い相談はサンプル記録として用意しています。本人の発言は確認の手掛かりであり、公的書類との照合が済んだ情報とは分けます。

## この体験で見せること

- 氏名メモ「山田 春子」と死亡診断書「山田 はる子」の不一致を、推測で直さない
- 「確認します」という返信だけでは完了にしない
- 保留中も、火葬日程などほかの準備は進める
- 家族の提出依頼と、担当者の提出報告を分ける
- 許可証の交付・受領・引渡しを別々に確認する

対象は架空の葵市の固定シナリオです。全国共通の案内ではありません。

## 画面

- しるべに相談する
- 情報・書類を確認する
- 任せている手続きを見る

家族には、自分が答える必要のあることだけを前に出します。

## 起動方法

```bash
npm install
npm run dev
```

[http://localhost:3000](http://localhost:3000) で「手続きをはじめる」

## 検証

```bash
npm test
npx tsc --noEmit
npm run lint
npm run build
```

## 制約

- 固定シナリオの体験版です。外部送信はありません
- 実際の契約・届出・許可判断は行われません
- 本籍や氏名の不足は推測で埋めません
- 「火葬実施済み」「葬儀完了」とは表示しません
