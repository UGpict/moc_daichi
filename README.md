# SougiAgent

終活をする本人が、自分の希望と見積もりの分からないところを確認し、子どもに一枚で残す操作可能な Web モックです。
担当のしるべさん（AIサポート）が、やさしい言葉で一緒に進みます。役所の手続きは、必要になったあとに家族画面から見られます。

## できること

- 希望を見たあと、見積もりの書いていないところを確認する
- 葬儀社に聞いてよいかだけ、内容を見て決める
- 曖昧な返事は完了扱いにせず、もう一度聞いてよいか確認する
- 分かった条件から目安の金額を出し、子どもに一枚で残す
- 必要になったあとの手続きデモ（受領確認、本籍の確認先、日程変更、提出、照会、許可証）

最安値への誘導はしません。本人の希望に沿って、想定外の支出と家族の迷いを減らすことが目的です。

## 起動方法

必要環境: Node.js 22 以降、npm

```bash
npm install
npm run dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開きます。

## デモ操作順

### ご自身の準備（親向け）

1. `/` で「準備をはじめる」
2. 希望を見て、「見積もりを見る」
3. 書いていないところを確認し、質問を見て「この内容で聞いてよい」
4. 初回の返事のあと、搬送費がまだ分からない理由を見て「もう一度聞いてよい」
5. 目安の金額と、子どもに残す一枚を見る

親向けの画面ではデモ操作パネルは出しません。返事は自動で届きます。

### 家族への引継ぎ・手続き

1. 子どもが見る画面から「必要になったときの手続きを見る」
2. 「手続きの体験を始める」を押し、しるべさんの本籍の問いかけに答える
3. 「資料がある」または「分からない」で、確認の進み方が変わる
4. 日程の候補が届いたら、費用の変化を見て調整するか家族に相談する
5. 本籍が申請書へ反映され、提出の依頼と提出報告を分けて進める
6. 自治体照会・完了報告・許可証の交付／受領／引渡しを順に確認する

デモ操作パネルを開かなくても、回答・承認のあと次のサンプル返信が届きます。
承認や家族の判断は自動では行いません。停止ボタンと、下部の「デモ操作」は残してあります。

「最初からやり直す」で保存状態と進行中の演出を初期化します。
直接 URL を開いても空白やエラーにはなりません。

## 検証

```bash
npm test
npx tsc --noEmit
npm run lint
npm run build
```

金額計算、問い合わせ遷移、日程変更、照会の未完了判定のテストを `src/lib/*.test.ts` に置いています。

## Vercel へのデプロイ

このリポジトリは Next.js App Router の標準構成です。実際の公開操作はこのモック作業では行いません。

1. [Vercel](https://vercel.com) に GitHub リポジトリを連携する
2. Framework Preset は Next.js のままで問題ありません
3. ビルドコマンド `npm run build`、出力は Next.js 既定
4. 環境変数は不要です（バックエンド・認証・LLM API はありません）

CLI を使う場合:

```bash
npx vercel
```

## 制約

- 固定シナリオの体験版です。外部送信はありません
- 実際の送信・契約・予約・届出・許可判断は行われません
- 自治体によって手順は異なります。全国共通の案内ではありません
- 今回の手続きデモは、斎場予約を先に進める想定です
- 届出人・窓口への持参者・火葬許可申請者は別の役割として表示します
- 本籍などの不足情報は推測で埋めません
- 「対応します」だけでは照会完了にしません
- 許可証の交付・受領・引渡しは独立した確認です
- 「火葬実施済み」「葬儀完了」とは表示しません
