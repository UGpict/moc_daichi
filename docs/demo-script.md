# 画面収録用デモ（固定入力）

日付・場所・文言を変えない。LIVE 合格判定には使わない。収録前に `APP_RUNTIME` と `DEMO_DATE` を確認する。

## 固定値

| 項目 | 値 |
|---|---|
| 日付 | `.env.local` の `DEMO_DATE`（既定 2026-09-20、LIVE は Asia/Tokyo の当日へ繰り上げ） |
| 開始–終了 | 13:00–18:00 |
| 集合 | 名古屋駅（設定で東京駅に切替可。発表会場住所は未提供） |
| 自分の希望 | 散歩と展示 |
| 相手の希望 | 甘いもの（MUST / PARTNER_STATEMENT_REPORTED） |
| 固定 | 愛知県美術館 15:00–16:00 |
| 自動変更 | ON（未着手1件・PASS・予算増なし・終了遅延なし・移動増なし） |
| 振り返り原文 | カフェは喜んでた。展示は途中で疲れてた |

## 操作順

1. `/` ゲスト開始
2. `/plan/new` で上記を入れ、行程を作成
3. 判断トレース（審査員向け）を開く。モデル理由・費用・再計画差分を確認
4. 「このプランで決定」→ 雨シナリオ → 遅延シナリオ（FAIL は適用しない）
5. 振り返り → 確認質問 → 記憶を承認
6. 「この記憶を使って次のプランをつくる」で差分を見る

再現コマンド: `npm run demo:live`（DEV） / `APP_RUNTIME=LIVE npm run demo:live`（実データ）。5連は `npm run demo:five`。想定外入力は `npm run demo:chaos`。
